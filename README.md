# Nuestro primer año 💕

Página web estática (HTML, CSS y JavaScript). No necesita instalar nada.

- Abre `index.html` en el navegador para verla en tu computador.
- Para publicarla: GitHub → Settings → Pages → Deploy from a branch → `main` / `(root)`.
- Fotos en `img2/` (miniaturas de las cintas en `img2/t/`). Textos, fechas y listas de fotos en `js/data.js`.
